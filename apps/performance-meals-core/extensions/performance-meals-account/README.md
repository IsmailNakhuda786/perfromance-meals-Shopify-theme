# Customer account: My Plan

Native customer-account full-page extension (`customer-account.page.render`, API 2026-07). It displays only the signed-in Shopify customer's app-backed menu selection/order state. Native Shopify Orders remains the unified Ready Series / Meal Plan / Gift Card history.

The endpoint is a build-time trusted HTTPS origin generated by the app's `configure:account` script. The generated module is ignored by Git; no development-store identifier or token is shipped in extension source. Get a fresh Shopify session token for the request; the app validates it with the official Shopify authenticator and filters records by its customer GID and allowlisted shop.

No invented rewards balance or subscription pause/cancel controls are present. Subscription-provider permissions and merchant rules must be integrated before those actions exist. The CLI-generated example reward messages were removed.

The dev preview works independently of a published theme. A permanent app backend and merchant activation of the released page/navigation are required before production use.

# Private environment setup

No .env files or credentials are included. Configure these documented variables
locally, using private environment files excluded from Git:

- `DATABASE_URL`
- `ALLOWED_SHOP`
- `SHOPIFY_API_KEY`
- `SHOPIFY_API_SECRET`
- `SHOPIFY_APP_URL`
- `PERFORMANCE_MEALS_APP_URL`
- `SCOPES`
- `DIRECT_DATABASE_URL`

Follow docs/CORE-DEPLOYMENT.md and the Core README for database and runtime setup.
